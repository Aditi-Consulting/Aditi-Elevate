# Vowel Counter

This project contains a simple Python function that counts the number of vowels in a given string.

## Features

- Counts both uppercase and lowercase vowels
- Handles non-string input safely by returning `0`
- Uses only Python's built-in features

## File Structure

- `src/count_vowels.py` - contains the `vowels_count` function and example usage

## Usage

```python
from src.count_vowels import vowels_count

result = vowels_count("Hello World!")
print(result)  # Output: 3
```

## Run the script

```bash
py .\src\count_vowels.py
```

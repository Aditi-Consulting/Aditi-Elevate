# File Line Counter

This project contains a simple Python script that counts the number of lines in a text file.
Write a Python program that: 
Reads a text file. 
Counts the number of lines. 
Handles the case where the file does not exist. 

## Files

- `src/File_lines_count.py` - Python script that reads a file and returns the total number of lines.
- `text.txt` - sample text file used by the script.

## How to run

```bash
py .\src\File_lines_count.py
```

## Notes

- The script uses only Python's built-in file handling.
- If you want to count another file, update the file path in the script before running it.

## Requirements

This project does not require any third-party packages. Python 3.x is enough.

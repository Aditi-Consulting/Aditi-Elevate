
# Python Vowel Counter

## Project Description

This Python program accepts a string from the user and counts the total number of vowels (a, e, i, o, u) present in the string.

It uses a reusable function and handles both uppercase and lowercase letters.

## Project Structure

```text
coding-question-02/
│
└── src/
    └── coding-question-02.py
```

## Sample Input

```text
Enter string: Hello World
```

## How to Run the Program

1. Make sure Python is installed on your system.
2. Open the terminal in the `src` directory.
3. Run the following command:

```bash
python coding-question-02.py
```

## Expected Output

```text
3
```

The output is `3` because "Hello World" contains three vowels (e, o, o).

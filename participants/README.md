# Participant submissions

Create a folder here using your GitHub username, then add your assessment work
under the appropriate learning area, chapter, and assessment:

```text
participants/<github-username>/<learning-area>/chapter-01-<chapter-name>/assessment-01-<assessment-name>/
```

Use lowercase folder names with hyphens. Keep your work inside your own
participant folder, and follow the submission instructions in the repository
root [README](../README.md).
